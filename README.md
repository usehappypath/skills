# Happy Path skills

Skills that teach coding agents how to work with [Happy Path](https://usehappypath.github.io): live-site QA that files confirmed bugs as GitHub issues.

## Claude Code
```
/plugin marketplace add usehappypath/skills
/plugin install happypath@usehappypath
```

## Codex and other agents
Paste [AGENTS-snippet.md](AGENTS-snippet.md) into your repo's `AGENTS.md`, or point your agent at https://usehappypath.github.io/llms.txt.
